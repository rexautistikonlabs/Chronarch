# ATTRIBUTION (K17)

Chronarch stands on three lineages. Attribution is a kernel module
(`K17_attribution`), hashed into the manifest — the organism cannot forget
where its organs came from.

## Cyberphysics / Cypher Tempre — memory + cognition

The Timechain-of-rings memory model, covenant, faculties (senses and
modalities), two-layer PoQ (advisory self-score vs challenge attestation),
Cambium proposal drafting, Chronosynaptic commitments, Continuum task
heads, hippocampus/recall commitments, and k-of-n head witnesses follow the
Cyberphysics lineage: `cyberphysicsai/cypher-tempre-genesis` and
cyberphysics.ai.

Chronarch **rebuilds these primitives as protocol objects** — schemas,
opcodes, and state machines — it does not fork Tempre Python skills into
validators and does not reproduce copyrighted sources.

## Rex Autistikon method + biotensegrity — health + nervous system

The nervous system imports a *method*, analogically: measure restriction at
named interfaces; represent a latent restriction/prestress state; predict
load transmission through the network tensegrity; test — and treat a failed
prediction as falsifying the model (G18). The biotensegrity mapping
(compression members, tension members, prestress, continuous tension with
discontinuous compression) follows biotensegrity principles as engineering
analogy.

**This is not a medical product.** Chronarch imports no autism claims, no
diagnoses, and no clinical scoring instruments.

consensus physics. The MVP abstracts space units and stubs slots; the

`cas_availability_root`, `gym_attestation_root`, `hearth_root`,
